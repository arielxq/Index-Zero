# 常見 GUI 與 App 解決方案

## 資料流

```text
硬體資料 → Python／後端 → Tkinter、Gradio、FastAPI、Thunkable 或 Blynk → 使用者
```

| 方案 | 適合用途 | 主要限制 |
| --- | --- | --- |
| Tkinter | 本機桌面工具 | 複雜跨裝置介面需更多設計 |
| Gradio | 快速 Web 原型 | 長期多人服務需額外架構 |
| FastAPI | API Gateway | 需要另建前端 |
| Thunkable | 手機 App | 受平台元件與部署方式限制 |
| Blynk | 快速 IoT 控制 | 依賴平台服務 |
