# 06｜74HC595：辨識並驅動裸 8×8 點陣

## 本頁資料流

```text
圖案矩陣 → ESP32 位元資料 → 74HC595 串列輸入 → 行列掃描 → 8×8 LED
```

## 學習重點

裸點陣不是把八個 GPIO 直接當成一張圖片，而是要快速切換列與欄。`74HC595` 負責把串列位元轉成平行輸出，ESP32 負責時序與掃描。

## 任務

1. 先辨識點陣的行列方向與共陽／共陰特性。
2. 用單列、單欄測試確認接腳排列。
3. 以固定圖樣驗證 74HC595 的資料順序。
4. 加入快速掃描，觀察亮度、殘影與方向。

## 除錯資料流

```text
全暗 → 電源／共地 → 移位順序 → 行列極性 → 掃描延遲 → 圖案方向
```

實際行列腳位與程式常數應以主線硬體配置頁及你的已驗證接線為準，不要把 MAX7219 的模組腳位套到裸點陣。
