# 01｜用 uv 建立 Python 虛擬環境

## 本頁資料流

```text
專案需求 → uv → pyproject.toml → 虛擬環境 → 套件 → Python 程式
```

## 學習目標

- 建立可重現的 Python 專案。
- 了解虛擬環境與套件依賴的責任。
- 為後續 `pyserial`、Pandas、Matplotlib 與 Gradio 做準備。

## 任務

```bash
uv init aiot-notes
cd aiot-notes
uv add pyserial pandas matplotlib gradio
uv run python -c "print('AIoT environment ready')"
```

輸出應顯示 `AIoT environment ready`。之後所有 Python 指令都優先使用 `uv run`，避免套件被安裝到錯誤的全域環境。

## 完成檢查

- 專案有 `pyproject.toml`。
- `uv run python --version` 能執行。
- 套件安裝紀錄與程式碼位於同一個專案。
